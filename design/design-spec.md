# AN7LN Security design system

The four accepted concepts in `design/concepts/` are the visual source of truth.

## Direction

- Theme: public research archive, not a hacker-theme template.
- Background: deep ink navy `#091018`.
- Primary text: bone white `#f2efe7`.
- Muted text: steel `#7f8b96`.
- Accent: amber `#e9b949`.
- Critical semantic color: `#e45b55`.
- Display typography: tall condensed grotesk; body: neutral sans; metadata: monospace.
- Geometry: square, ruled, low-radius, no glow, no gradients, no glass.
- Containers: open bands, ledger rows, rails and lists. Cards are not the default.

## Component families

- Quiet horizontal header with wordmark, six navigation links and search control.
- Desktop archive rail / mobile archive marker.
- Display headings with amber cursor rule.
- Ruled research rows with semantic severity labels.
- Numbered reading rows and timeline rows.
- Bone-white Arsenal band.
- Search dialog with real Pagefind results and local development fallback.
